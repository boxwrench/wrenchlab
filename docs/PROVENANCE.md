# Provenance

WrenchLab v0 originated from a private DSH prototype whose deterministic
execution/resource foundation was frozen before this public bootstrap.

The private preservation point was commit
`9e6e30795692c6684062aa36f96c411ad84b0783`, tagged
`pre-wrenchlab-foundation`, with a 104/104 regression result and separate
qualification records. That history, raw campaigns, live host configuration
and service environment are not imported into this repository.

This public tree preserves the reusable behavior and sanitized public summaries,
not private machine evidence or provider-specific routing. The provenance claim
does not claim that unqualified physical cross-host execution or future WrenchLab
features already exist.
